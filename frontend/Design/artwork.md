# Prototype artwork

`TorontoParties/Resources/Assets.xcassets/Disco.imageset/disco.png` was created with the built-in image generation tool as a standalone asset. It is generated concept imagery, not a photograph of an actual Toronto event.

Generation prompt:

> Create a single square editorial still-life photograph-style image for a sleek monochrome Bollywood nightlife app. One silver mirrored disco ball cropped dramatically on the upper right, occupying 65 percent of the frame, suspended in a deep black real studio environment. Authentic imperfect mirror tiles, crisp white reflections from a single direct flash, faint subtle silver light flecks on background, fine analog grain. Completely black and white, tactile photographic aesthetic, not glossy CGI. Empty negative space bottom left. No people, no words, no logos, no interface, no borders. Asset only, not a mockup.
